# Start Here: SeaVision for New Users

This guide is for first-time users who are not computer vision specialists.

SeaVision helps you:

1. Run a detector on marine video.
2. Review and correct detections in the GUI.
3. Export validated detections for model training.
4. Optionally deploy trained models to edge devices.

## Before you begin

You need:

- Python 3.10+
- `pip`
- Video files (`.ts`, `.mp4`, or `.avi`)
- A detection CSV (if you want to review existing detections)

## 10-minute quick path

1. Clone the repository:

```bash
git clone https://github.com/mariolambrette/SeaVision
cd SeaVision
```

2. Install GUI mode:

```bash
python -m pip install ".[gui]"
```

3. Launch the GUI:

```bash
seavision-gui
```

4. Start a review session:
- Use **File -> New Session** (or `Ctrl+N`)
- Select your detection CSV
- Select the folder containing the source videos

5. Review quickly with keyboard:
- `N`: next unreviewed detection
- `C`: confirm
- `R`: reject
- `S`: skip

6. Save and export:
- `Ctrl+S`: save `.seavision-session`
- `Ctrl+E`: export confirmed/corrected detections to CSV

## What key terms mean

- Detection CSV: A table of detections generated by a model or pipeline.
- Session file (`.seavision-session`): Your saved review state (decisions, edits, manual detections).
- Confidence: A model score for how likely a detection is correct.
- Corrected detection: A detection whose box geometry you edited.
- Artifact: A packaged model output directory used by `seavision-edge` on an edge device.
